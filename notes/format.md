# 存档格式

这一档解开后是 6,488,836 字节，按小端 32 位整数看。下面的「下标」都是这个整数数组的下标，从 0 数，含最前面两个校验和。

## 外层

| 偏移 | 内容 |
|---|---|
| `0x000`–`0x213` | 文件头，原样复制。魔数是 UTF-16 的 `S5SD502E`，后面是标题 |
| `0x1E0` | 解压后的字节数。这一档是 `0x630304` |
| `0x214` | 五个整数：`count`、正向 CRC、反射 CRC、密钥、除数 |
| `0x228` | 密文，长度 `count * 4` 字节 |

`count` 是密文前面那层包装的字节数除以 2。解密循环跑 `count >> 1` 次，每次吃 8 字节、吐 4 字节。

```
d = divisor & 0xFFFF
word = (((w0 / d) << 16) + (w1 / d)) XOR key
key = (key + 0x0B0B0B0B) & 0xFFFFFFFF
divisor = (divisor + 0xB02) & 0xFFFFFFFF
```

两个 16 位商都必须整除。这一档的初始密钥是 `0x1ABF0C57`，初始除数是 `0x777`。密钥和除数写在文件里，随档变化，不要写死别的作品的密钥。

## 包装和 LZSS

解密结果开头是三个整数：解压后大小、同一大小、压缩后大小。后面是 Okumura LZSS，再补 0 到 4 字节对齐。

窗口 0x1000，初始全 0，环上的写入位置从 `0xFEE` 开始。标志字节先或上 `0xFF00`，右移之后若 `(flags & 0x100) == 0` 就再读一个标志。最低位是第一个记号，1 是原字节，0 是匹配。匹配偏移是 `b0 | ((b1 & 0xF0) << 4)`，长度是 `(b1 & 0xF) + 3`，也就是 3 到 18。

第一个整数等于第三个整数时，加载器会跳过 LZSS 直接拷贝。不要走这条路。曾经因此得到一个约 12 MB 的文件，读档时在 `LoadTextBufData` 的 LZSS 里访问违例。

## 两个校验和

解压结果的前 8 字节是后面整段的两个校验和，不是游戏数据。

1. 正向 CRC。多项式 `0x04C11DB7`，初值 `0xFFFFFFFF`，`crc = (crc << 8) XOR table[(crc >> 24) XOR byte]`，最后取反。
2. 反射 CRC，就是 zlib 的 CRC32。

外层那两个 CRC 用同样的算法，范围是密文。改完整数要重算内层校验和，压缩加密后再重算外层。

## 读进内存之后

版本字段在文件头附近，这一档是 3，走 LZSS 那条加载路径。游戏数据从解压结果的第 8 字节开始。脚本变量再经过一次变换才放进变量数组：

```
stored = ROL(ROR(value, 7) XOR key, 21)
value  = ROL(ROR(stored, 21) XOR key, 7)
```

这个 key 在引擎对象 `+0x716BC`，每次启动都会变。变量数组指针在引擎对象 `+0x7012C`。下标换算：

```
变量下标 = 存档整数下标 - 5865
```

所以金币 `9873` 是变量 `4008`，等级表 `1246717` 是变量 `1240852`。引擎对象本身每次启动的地址不同。文件改档不需要它。

## 认过的字段

金币在 `9873`。左边是 `0, 569, 360`，右边紧挨着 `190`。早期三档里只有这个数按 `0 → 180 → 180` 涨过，所以它是钱包。`76526` 和 `76527` 是另一份同样的金额，两份一起改，界面才不会留着旧数。

等级表在 `1246717`，按角色顺序：马克、苏菲亚、瑞理，后面是 0。第 6 天那档原来是 `4, 1, 4`。更早一档同一位置是 `3, 0, 3`，苏菲亚还没入队。往后 100 个整数是升到下一级的经验，第 6 天是 `271, 0, 122`。经验留着。98 级升到 99 级要 `50 × 99² = 490050`，这点经验不会把人送上 99。

这些不是等级：

| 位置 | 实际是什么 |
|---|---|
| `1120528` 起，每 12 个数一名角色 | 战斗面板。第 0 项是 HP，第 1 项是 SP。打开角色页会按等级重算，改了也会被盖回去 |
| `1233517` 的 `581, 382, 553` | 上面那三个人的 HP，100 个数之后还有一份 |
| `1233717` 的 `21, 32, 23` | 三个人的 SP，同样有一份副本 |
| 解压结果下标 4 | 文件头里的一个计数。这一档是 4，另一档是 16，自动存档是 37，角色面板却还是早期的 HP |

装备不在等级表里。只改 `1246717` 起的三个等级，武器和衣服不动。

战斗面板 12 个数和装备页的对应，留着避免再认错：`HP, SP, ?, ?, 物攻, 物防, 魔攻, 魔防, ?, ?, 敏捷, 咏唱`。第 6 天马克那行开头是 `581, 21`，装备页上就是 HP 581、SP 21。
